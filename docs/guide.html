Earn without photographing your meter

Normally you photograph your meter to earn B3TR. If something in your home can already read the meter, it can send the reading for you — and you never photograph again. Start by finding your setup below.

Which setup do you have?

I use Home Assistant

Works with almost any meter HA already reads. Install our add-on, or paste a few lines of YAML.

Easiest

I have a HomeWizard P1

No Home Assistant needed. A small helper finds your meter on the network by itself.

Some tech

I have another P1 reader

dsmr-reader, P1 Monitor, Shelly and friends — anything that serves its data as JSON.

Technical

None of these

Then keep photographing your meter. It works just as well and earns exactly the same. Nothing to set up.

No setup
First, once: set your starting pointWhichever route you pick, do one normal photo submission in the app first. That tells the app where your meter started — without it, automatic readings can't be paid out.

All automatic routes: get your token

  1. Copy your device token

    In the app: Submit → ⚡ Have a P1 reader? → ⚙️ Automatic setup → “Get my device token”. Copy it.

    What it isA long code that says “these readings belong to my wallet”. Keep it private — anyone holding it can send readings in your name.

Route A — Home Assistant (any meter)

Two ways. The add-on is the simplest if you have a HomeWizard; the YAML works with any meter Home Assistant already shows you.

With our add-on (no YAML)

  1. Add the repository

    In Home Assistant: Settings → Add-ons → Add-on Store → ⋮ (top right) → Repositories. Paste this and press Add.

    Repository address
    https://github.com/GreenUtilityLog/GreenUtilityLog

  2. Install the add-on

    It appears at the bottom of the store as GreenUtilityLog Meter Bridge. Open it and press Install.

  3. Paste your token and start

    On the Configuration tab paste your token into token, press Save, then Start on the Info tab.

    Check the Log tabWithin a minute you should see pushed 8421.3 kWh ✓.

With your own sensor (any meter)

  1. Find your meter sensor

    In Home Assistant: Developer tools → States. Filter on import and pick the one in kWh whose value keeps counting up — that is your total. Entity ids differ per install, so use yours.

  2. Add these lines

    Put this in configuration.yaml, replacing the entity and your token, then restart Home Assistant.

    configuration.yaml + automations.yaml
    rest_command:
  gul_push:
    url: "https://greenutilitylog-rewards.onrender.com/meter-ingest"
    method: POST
    content_type: "application/json"
    payload: '{"token":"YOUR_TOKEN","reading":{{ states("sensor.YOUR_ENTITY") | float }}}'

# automations.yaml — send once an hour
- alias: Push meter to GreenUtilityLog
  trigger: { platform: time_pattern, hours: "/1" }
  action: { service: rest_command.gul_push }

Route B — HomeWizard P1, without Home Assistant

  1. Turn on the Local API

    In the HomeWizard Energy app: Settings → Meters → your P1 → Local API → ON. This lets your own network read the meter.

  2. Open a terminal on a device that stays on

    Windows: press Start, type PowerShell. Mac: open Terminal. Pi / NAS: its terminal, or over SSH.

    You need Node.js 18+Not installed? Get it from nodejs.org first, or the command below won't run.

  3. Paste this, with your own token

    Replace YOUR_TOKEN, press Enter, and leave the window open.

    One-off setup
    git clone https://github.com/GreenUtilityLog/GreenUtilityLog
cd GreenUtilityLog/bridge
GUL_TOKEN=YOUR_TOKEN node index.js

  4. Check it found the meter

    You should see the meter being discovered and then pushed.

    Expected outputfound HomeWizard at 192.168.… then pushed 8421.3 kWh ✓

Route C — Another P1 reader

The same helper reads any device that serves its data as JSON over HTTP — you just tell it where.

  1. Find your reader's data URL

    Open your reader's web page and look for the address that returns raw JSON (often something like /api/v1/data or /api/v2/sm/actual). Exact paths differ per brand — check your reader's own documentation.

  2. Start the helper with that URL

    Replace the URL and your token. If the reading isn't found automatically, add READ_FIELD= with the dot-path to the kWh value in that JSON.

    Any HTTP/JSON reader
    git clone https://github.com/GreenUtilityLog/GreenUtilityLog
cd GreenUtilityLog/bridge
GUL_TOKEN=YOUR_TOKEN READ_URL=http://192.168.1.60/api/v1/data node index.js

  3. Check it worked

    The helper prints what it pushed.

    Expected outputpushed 8421.3 kWh ✓

Finally: claim it in the app

  1. Your reading appears by itself

    In the app open Submit. Under “Auto-received” you'll see your meter total and when it arrived.

  2. Tap “Submit — no photo”

    That's it. From now on your meter sends its reading every hour and you only claim it.

🇧🇪 Belgium (Fluvius meters)Digital Fluvius meters send encrypted data. Ask Fluvius for your free decryption key and enter it once in your reader's app — after that everything works the same.

If something doesn't work

You seeWhat to do
No HomeWizard foundYour network blocks auto-discovery. Find your P1's IP in the HomeWizard app and set hw_ip (add-on) or add HW_IP=192.168.1.50 before the command.
couldn't find a total import kWhThe reader returned JSON the helper didn't recognise. Set READ_FIELD to the dot-path of the cumulative kWh value.
Nothing under “Auto-received”Check the token is pasted correctly and the helper is still running on the same network as the meter.
the automatic reading is staleA reading must be under 48 hours old to pay out — make sure the add-on or terminal is still running.
submit one photo reading firstYou skipped the starting point. Do one normal photo submission, then try again.
Still stuck? Send a message with what the Log tab (or terminal) shows — it usually says exactly what's missing.

Normaal fotografeer je je meter om B3TR te verdienen. Kan er thuis al iets je meter uitlezen, dan stuurt dát de stand door — en hoef jij nooit meer te fotograferen. Zoek hieronder je situatie op.

Welke situatie heb jij?

Ik gebruik Home Assistant

Werkt met vrijwel elke meter die HA al uitleest. Installeer onze add-on, of plak een paar regels YAML.

Makkelijkst

Ik heb een HomeWizard P1

Geen Home Assistant nodig. Een klein hulpprogramma vindt je meter zelf op het netwerk.

Beetje techniek

Ik heb een andere P1-reader

dsmr-reader, P1 Monitor, Shelly en dergelijke — alles wat z’n data als JSON aanbiedt.

Technisch

Geen van deze

Blijf dan je meter fotograferen. Dat werkt net zo goed en levert precies hetzelfde op. Niets in te stellen.

Niets instellen
Eerst, eenmalig: zet je startpuntWelke route je ook kiest, doe eerst één gewone foto-inzending in de app. Daarmee weet de app waar je meter begon — zonder dat kunnen automatische standen niet uitbetalen.

Verdienen, ohne den Zähler zu fotografieren

Normalerweise fotografierst du deinen Zähler, um B3TR zu verdienen. Kann bei dir zu Hause schon etwas den Zähler auslesen, sendet das den Stand für dich — und du fotografierst nie wieder. Such unten deine Situation.

Welche Situation hast du?

Ich nutze Home Assistant

Funktioniert mit fast jedem Zähler, den HA schon ausliest. Installiere unser Add-on oder füge ein paar Zeilen YAML ein.

Am einfachsten

Ich habe einen HomeWizard P1

Kein Home Assistant nötig. Ein kleines Hilfsprogramm findet deinen Zähler selbst im Netzwerk.

Etwas Technik

Ich habe einen anderen P1-Reader

dsmr-reader, P1 Monitor, Shelly und Co. — alles, was seine Daten als JSON anbietet.

Technisch

Nichts davon

Dann fotografiere deinen Zähler weiter. Das funktioniert genauso gut und bringt exakt dasselbe. Nichts einzurichten.

Nichts einrichten
Zuerst, einmalig: Startpunkt setzenEgal welche Route: mach zuerst eine normale Foto-Einreichung in der App. Damit weiß die App, wo dein Zähler startete — sonst können automatische Stände nicht ausgezahlt werden.

Normalement vous photographiez votre compteur pour gagner des B3TR. Si quelque chose chez vous sait déjà lire le compteur, il peut envoyer le relevé à votre place — et vous ne photographiez plus jamais. Trouvez votre cas ci-dessous.

J'utilise Home Assistant

Guía para testers

Gana sin fotografiar tu contador

Normalmente fotografías tu contador para ganar B3TR. Si algo en tu casa ya sabe leer el contador, puede enviar la lectura por ti — y no vuelves a fotografiar. Busca tu caso abajo.

¿Cuál es tu caso?

Uso Home Assistant

Funciona con casi cualquier contador que HA ya lee. Instala nuestro add-on, o pega unas líneas de YAML.

Lo más fácil

Tengo un HomeWizard P1

Sin Home Assistant. Un pequeño programa encuentra tu contador solo en la red.

Algo técnico

Tengo otro lector P1

dsmr-reader, P1 Monitor, Shelly y similares — cualquiera que sirva sus datos en JSON.

Técnico

Ninguno

Sigue fotografiando tu contador. Funciona igual de bien y da exactamente lo mismo. Nada que configurar.

Sin configurar
Primero, una vez: fija tu punto de partidaElijas la ruta que elijas, haz primero un envío con foto normal en la app. Así la app sabe dónde empezó tu contador — sin eso las lecturas automáticas no pueden pagarse.

Todas las rutas automáticas: consigue tu token

  1. Copia tu token

    En la app: Submit → ⚡ Have a P1 reader? → ⚙️ Automatic setup → «Get my device token». Cópialo.

    Qué esUn código largo que dice «estas lecturas son de mi wallet». Mantenlo privado — quien lo tenga puede enviar lecturas en tu nombre.

Ruta A — Home Assistant (cualquier contador)

Dos formas. El add-on es lo más simple si tienes un HomeWizard; el YAML funciona con cualquier contador que Home Assistant ya muestre.

Con nuestro add-on (sin YAML)

  1. Añade el repositorio

    En Home Assistant: Ajustes → Complementos → Tienda → ⋮ (arriba a la derecha) → Repositorios. Pega esto y pulsa Añadir.

    Dirección del repositorio
    https://github.com/GreenUtilityLog/GreenUtilityLog

  2. Instala el add-on

    Aparece al final de la tienda como GreenUtilityLog Meter Bridge. Ábrelo y pulsa Instalar.

  3. Pega tu token e inicia

    En la pestaña Configuración pega el token en token, pulsa Guardar y luego Iniciar en la pestaña Info.

    Mira la pestaña RegistroEn un minuto deberías ver pushed 8421.3 kWh ✓.

Con tu propio sensor (cualquier contador)

  1. Encuentra el sensor de tu contador

    En Home Assistant: Herramientas para desarrolladores → Estados. Filtra por import y coge el de kWh cuyo valor sigue subiendo — ese es tu total. Los identificadores varían por instalación, usa el tuyo.

  2. Añade estas líneas

    Pon esto en configuration.yaml, sustituye la entidad y tu token, y reinicia Home Assistant.

    configuration.yaml + automations.yaml
    rest_command:
  gul_push:
    url: "https://greenutilitylog-rewards.onrender.com/meter-ingest"
    method: POST
    content_type: "application/json"
    payload: '{"token":"TU_TOKEN","reading":{{ states("sensor.TU_ENTIDAD") | float }}}'

# automations.yaml — enviar cada hora
- alias: Push meter to GreenUtilityLog
  trigger: { platform: time_pattern, hours: "/1" }
  action: { service: rest_command.gul_push }

Ruta B — HomeWizard P1, sin Home Assistant

  1. Activa la API local

    En la app HomeWizard Energy: Ajustes → Contadores → tu P1 → Local API → ON. Así tu red puede leer el contador.

  2. Abre una terminal en un dispositivo que quede encendido

    Windows: Inicio, escribe PowerShell. Mac: abre Terminal. Pi / NAS: su terminal, o por SSH.

    Necesitas Node.js 18+¿No lo tienes? Descárgalo de nodejs.org, si no el comando no funcionará.

  3. Pega esto, con tu token

    Sustituye TU_TOKEN, pulsa Enter y deja la ventana abierta.

    Configuración única
    git clone https://github.com/GreenUtilityLog/GreenUtilityLog
cd GreenUtilityLog/bridge
GUL_TOKEN=TU_TOKEN node index.js

  4. Comprueba que encontró el contador

    Deberías ver el contador detectado y enviado.

    Salida esperadafound HomeWizard at 192.168.… y luego pushed 8421.3 kWh ✓

Ruta C — Otro lector P1

El mismo programa lee cualquier dispositivo que sirva sus datos en JSON por HTTP — solo le dices dónde.

  1. Encuentra la URL de datos de tu lector

    Abre la página web de tu lector y busca la dirección que devuelve JSON en bruto (a menudo /api/v1/data o /api/v2/sm/actual). Las rutas exactas varían por marca — consulta la documentación de tu lector.

  2. Inicia el programa con esa URL

    Sustituye la URL y tu token. Si la lectura no se encuentra automáticamente, añade READ_FIELD= con la ruta al valor kWh en ese JSON.

    Cualquier lector HTTP/JSON
    git clone https://github.com/GreenUtilityLog/GreenUtilityLog
cd GreenUtilityLog/bridge
GUL_TOKEN=TU_TOKEN READ_URL=http://192.168.1.60/api/v1/data node index.js

  3. Comprueba que funcionó

    El programa muestra lo que ha enviado.

    Salida esperadapushed 8421.3 kWh ✓

Por último: reclama en la app

  1. Tu lectura aparece sola

    En la app abre Submit. Bajo «Auto-received» verás tu lectura y cuándo llegó.

  2. Toca «Submit — no photo»

    Listo. Desde ahora tu contador envía su lectura cada hora y tú solo reclamas.

🇧🇪 Bélgica (contadores Fluvius)Los contadores Fluvius digitales envían datos cifrados. Pide tu clave gratuita a Fluvius e introdúcela una vez en la app de tu lector — después todo funciona igual.
