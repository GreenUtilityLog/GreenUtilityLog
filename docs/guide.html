Earn without photographing your meter

Normally you photograph your meter to earn B3TR. If something in your home can already read the meter, it can send the reading for you — and you never photograph again. Start by finding your setup below.

Which setup do you have?

I use Home Assistant

Works with almost any meter HA already reads. Install our add-on, or paste a few lines of YAML.

Easiest

I have a HomeWizard P1

No Home Assistant needed. A small helper finds your meter on the network by itself.

Some tech

I have another P1 reader

dsmr-reader, P1 Monitor, Shelly and friends — anything that serves its data as JSON.

Technical

None of these

Then keep photographing your meter. It works just as well and earns exactly the same. Nothing to set up.

No setup
First, once: set your starting pointWhichever route you pick, do one normal photo submission in the app first. That tells the app where your meter started — without it, automatic readings can't be paid out.

Does this work where you live?

The socket on your meter differs per country, so not every reader works everywhere. What always works: if Home Assistant already shows your meter's total, Route A works — whatever country you're in.

CountryYour meter hasWhat to use
🇳🇱 NetherlandsP1 port (RJ12)Any route. HomeWizard works out of the box.
🇧🇪 BelgiumP1 port (RJ12)Same — plus the free Fluvius decryption key, once.
🇱🇺 LuxembourgP1 port (Dutch DSMR)Same as the Netherlands.
🇸🇪 Sweden · 🇫🇮 FinlandHAN port (RJ12)A P1/HAN reader, or Home Assistant.
🇩🇰 DenmarkHAN (pin header, encrypted)A reader with the right connector, or Home Assistant.
🇳🇴 NorwayHAN (RJ45, M-BUS)A Norwegian HAN reader + Home Assistant.

Not sure? Open Home Assistant and look for your meter under Developer tools → States. If a kWh value is there and counting up, you're set.

All automatic routes: get your token

  1. Copy your device token

    In the app: Submit → ⚡ Have a P1 reader? → ⚙️ Automatic setup → “Get my device token”. Copy it.

    What it isA long code that says “these readings belong to my wallet”. Keep it private — anyone holding it can send readings in your name.

Route A — Home Assistant (any meter)

Two ways. Our integration is the easiest and works with any meter Home Assistant already shows you; the YAML does the same by hand if you'd rather not install anything.

With our integration (recommended)

  1. Add us to HACS

    In Home Assistant: HACS → ⋮ (top right) → Custom repositories. Paste the address below, choose type Integration, press Add.

    Repository address
    https://github.com/GreenUtilityLog/GreenUtilityLog

  2. Install and restart

    Open GreenUtilityLog in the HACS list, press Download, then restart Home Assistant.

  3. Add the integration

    Go to Settings → Devices & services → Add integration and search for GreenUtilityLog. Paste your token, pick the sensor holding your cumulative kWh, and choose how often to send.

    Check it workedA sensor Last sent reading appears with your meter total. Its attributes show the time it was sent and any error.

With your own sensor (any meter)

  1. Find your meter sensor

    In Home Assistant: Developer tools → States. Filter on import and pick the one in kWh whose value keeps counting up — that is your total. Entity ids differ per install, so use yours.

  2. Add these lines

    Put this in configuration.yaml, replacing the entity and your token, then restart Home Assistant.

    configuration.yaml + automations.yaml
    rest_command:
  gul_push:
    url: "https://greenutilitylog-rewards.onrender.com/meter-ingest"
    method: POST
    content_type: "application/json"
    payload: '{"token":"YOUR_TOKEN","reading":{{ states("sensor.YOUR_ENTITY") | float }}}'

# automations.yaml — twice a day (you can claim once per 20h)
- alias: Push meter to GreenUtilityLog
  trigger: { platform: time_pattern, hours: "/12" }
  action: { service: rest_command.gul_push }

Route B — HomeWizard P1, without Home Assistant

  1. Turn on the Local API

    In the HomeWizard Energy app: Settings → Meters → your P1 → Local API → ON. This lets your own network read the meter.

  2. Open PowerShell (or a terminal)

    Windows: press Start, type PowerShell, press Enter. Mac: open Terminal. Raspberry Pi / NAS: its own terminal, or over SSH. Everything below is typed into that window.

  3. Check whether you already have Node

    Type this and press Enter. A version number — anything from v18 up — means you are set, and you can skip the next step. An error instead means Node isn’t installed yet.

    Windows · Mac · Linux
    node -v

  4. Install Node.js, if that gave an error

    Windows: paste the line below; press Y if it asks you to accept the source terms. Mac: the LTS installer from nodejs.org, or brew install node. Raspberry Pi / Debian: sudo apt install nodejs. Then close that window and open a new one — a window that was already open keeps the old PATH, so node would still not be found. Check again with node -v.

    Windows — PowerShell
    winget install OpenJS.NodeJS.LTS

  5. Paste one line, press Enter

    It downloads the helper and starts it. Leave the window open — that is the whole setup.

    Windows — PowerShell
    iwr https://greenutilitylog.github.io/GreenUtilityLog/gul.js -OutFile gul.js; node gul.js
    Mac · Linux · Raspberry Pi
    curl -fsSL https://greenutilitylog.github.io/GreenUtilityLog/gul.js -o gul.js && node gul.js

  6. Paste your token when it asks

    It asks once and remembers it, so from then on you start it with just node gul.js. Then it finds the meter and sends the reading.

    What you should see, in orderPaste your device token… → found HomeWizard at 192.168.… → pushed 8421.3 kWh ✓

Route C — Another P1 reader

The same helper reads any device that serves its data as JSON over HTTP — you just tell it where. Do steps 2–4 of Route B first (terminal and Node); only the command below is different.

  1. Find your reader's data URL

    Open your reader's web page and look for the address that returns raw JSON (often something like /api/v1/data or /api/v2/sm/actual). Exact paths differ per brand — check your reader's own documentation.

  2. Start the helper with that URL

    Put your own address in place of the example one; it asks for your token itself. If the reading isn't found automatically, add --field= with the dot-path to the kWh value in that JSON.

    Windows — PowerShell
    iwr https://greenutilitylog.github.io/GreenUtilityLog/gul.js -OutFile gul.js; node gul.js --url=http://192.168.1.60/api/v1/data
    Mac · Linux · Raspberry Pi
    curl -fsSL https://greenutilitylog.github.io/GreenUtilityLog/gul.js -o gul.js && node gul.js --url=http://192.168.1.60/api/v1/data

  3. Check it worked

    The helper prints what it pushed.

    Expected outputpushed 8421.3 kWh ✓
No machine that stays on?You don’t need one. Run node gul.js --once whenever it suits you: it reads the meter, sends the reading and closes. Then claim it in the app — the only rule is that the reading is under 48 hours old when you claim. A laptop you open now and then is enough; leaving the helper running only saves you from having to think about it.

Finally: claim it in the app

  1. Your reading appears by itself

    In the app open Submit. Under “Auto-received” you'll see your meter total and when it arrived.

  2. Tap “Submit — no photo”

    That's it. From now on your meter sends its reading by itself and you only claim it.

🇧🇪 Belgium (Fluvius meters)Digital Fluvius meters send encrypted data. Ask Fluvius for your free decryption key and enter it once in your reader's app — after that everything works the same.

If something doesn't work

You seeWhat to do
'node' is not recognizedNode.js isn’t installed, or that window was already open when you installed it. On Windows: winget install OpenJS.NodeJS.LTS. Elsewhere: nodejs.org. Then open a new terminal and paste the line again. You do not need git.
Nothing at all — no output, straight back to the promptAn old copy of the helper, from before 19 September. It had a bug that made it exit on Windows without printing anything. Download it again with the line above; the new one asks for your token.
no HomeWizard found on the networkYour network blocks auto-discovery — common on guest Wi-Fi and with VLANs. Look up your P1’s IP in the HomeWizard app and run node gul.js --ip=192.168.1.50. On the Home Assistant add-on, fill in hw_ip instead.
couldn't find a total import kWhIt reached the device but got nothing usable back: Local API is still off in the HomeWizard app, or this isn’t a P1 meter. For another brand of reader, use --url=.
couldn't find a kWh number at …Your reader’s JSON doesn’t use a name the helper knows. Add --field= with the dot-path to the value, e.g. --field=electricity.import_kwh.

submit one photo reading firstYour meter has no starting point yet. Do one normal photo submission in the app — automatic readings never set the first value, so that a device cannot invent its own baseline. After that it pays out.
usage … is outside the plausible rangeAlmost always a double-tariff meter: the display keeps two registers (1.8.1 and 1.8.2) and your photo captured one of them, while your reader reports the total of both — so your starting point and your reader are on different scales. the automatic reading is staleA reading has to be under 48 hours old at the moment you claim it. Run the helper again (or leave it running) and claim once it prints pushed … ✓.
Nothing under “Auto-received”The helper hasn’t pushed successfully yet. Look at its window: every cycle prints either pushed … ✓ or the reason it failed.

Verdien zonder je meter te fotograferen

Normaal fotografeer je je meter om B3TR te verdienen. Kan er thuis al iets je meter uitlezen, dan stuurt dát de stand door — en hoef jij nooit meer te fotograferen. Zoek hieronder je situatie op.

Welke situatie heb jij?

Ik gebruik Home Assistant

Werkt met vrijwel elke meter die HA al uitleest. Installeer onze add-on, of plak een paar regels YAML.

Makkelijkst

Ik heb een HomeWizard P1

Geen Home Assistant nodig. Een klein hulpprogramma vindt je meter zelf op het netwerk.

Beetje techniek

Ik heb een andere P1-reader

dsmr-reader, P1 Monitor, Shelly en dergelijke — alles wat z’n data als JSON aanbiedt.

Technisch

Geen van deze

Blijf dan je meter fotograferen. Dat werkt net zo goed en levert precies hetzelfde op. Niets in te stellen.

Niets instellen
Eerst, eenmalig: zet je startpuntWelke route je ook kiest, doe eerst één gewone foto-inzending in de app. Daarmee weet de app waar je meter begon — zonder dat kunnen automatische standen niet uitbetalen.

Route C — Een andere P1-reader

Hetzelfde hulpprogramma leest elk apparaat dat z’n data als JSON via HTTP aanbiedt — je zegt alleen waar. Doe eerst stap 2 t/m 4 van route B (terminal en Node); alleen het commando hieronder is anders.

    Open de webpagina van je reader en zoek het adres dat ruwe JSON teruggeeft (vaak zoiets als /api/v1/data of /api/v2/sm/actual). Exacte paden verschillen per merk — kijk in de documentatie van je reader.

    Zet je eigen adres op de plek van het voorbeeld; om je token vraagt hij zelf. Wordt de stand niet automatisch gevonden, zet er dan --field= bij met het pad naar de kWh-waarde in die JSON.

    Mac · Linux · Raspberry Pi
    curl -fsSL https://greenutilitylog.github.io/GreenUtilityLog/gul.js -o gul.js && node gul.js --url=http://192.168.1.60/api/v1/data

    Het hulpprogramma laat zien wat het verstuurd heeft.

Verdienen, ohne den Zähler zu fotografieren

Normalerweise fotografierst du deinen Zähler, um B3TR zu verdienen. Kann bei dir zu Hause schon etwas den Zähler auslesen, sendet das den Stand für dich — und du fotografierst nie wieder. Such unten deine Situation.

Welche Situation hast du?

Ich nutze Home Assistant

Funktioniert mit fast jedem Zähler, den HA schon ausliest. Installiere unser Add-on oder füge ein paar Zeilen YAML ein.

Am einfachsten

Ich habe einen HomeWizard P1

Kein Home Assistant nötig. Ein kleines Hilfsprogramm findet deinen Zähler selbst im Netzwerk.

Etwas Technik

Ich habe einen anderen P1-Reader

dsmr-reader, P1 Monitor, Shelly und Co. — alles, was seine Daten als JSON anbietet.

Technisch

Nichts davon

Dann fotografiere deinen Zähler weiter. Das funktioniert genauso gut und bringt exakt dasselbe. Nichts einzurichten.

Nichts einrichten
Zuerst, einmalig: Startpunkt setzenEgal welche Route: mach zuerst eine normale Foto-Einreichung in der App. Damit weiß die App, wo dein Zähler startete — sonst können automatische Stände nicht ausgezahlt werden.

Ruta C — Otro lector P1

El mismo programa lee cualquier dispositivo que sirva sus datos en JSON por HTTP — solo le dices dónde. Haz primero los pasos 2 a 4 de la ruta B (terminal y Node); solo cambia el comando de abajo.

  1. Encuentra la URL de datos de tu lector

    Abre la página web de tu lector y busca la dirección que devuelve JSON en bruto (a menudo /api/v1/data o /api/v2/sm/actual). Las rutas exactas varían por marca — consulta la documentación de tu lector.

  2. Inicia el programa con esa URL

    Pon tu propia dirección en lugar del ejemplo; el token te lo pide él mismo. Si la lectura no se encuentra automáticamente, añade --field= con la ruta al valor kWh en ese JSON.

    Windows — PowerShell
    iwr https://greenutilitylog.github.io/GreenUtilityLog/gul.js -OutFile gul.js; node gul.js --url=http://192.168.1.60/api/v1/data
    Mac · Linux · Raspberry Pi
    curl -fsSL https://greenutilitylog.github.io/GreenUtilityLog/gul.js -o gul.js && node gul.js --url=http://192.168.1.60/api/v1/data

  3. Comprueba que funcionó

    El programa muestra lo que ha enviado.

no HomeWizard found on the networkTu red bloquea la detección automática — habitual en wifi de invitados y con VLAN. Busca la IP de tu P1 en la app HomeWizard y ejecuta node gul.js --ip=192.168.1.50. Con el add-on de Home Assistant, rellena hw_ip.
couldn't find a total import kWhLlegó al dispositivo pero no recibió nada aprovechable: la API local sigue desactivada en la app HomeWizard, o esto no es un contador P1. Para otra marca de lector: --url=.
